The Need

Rural care doesn't fail from missing services.
It fails at the seams between them.

Every tier of India's public health system has a digital system doing its own job. Not one of them verifies that a handoff between tiers actually happened — so referrals die in transit, vaccine sessions open without supplies, and nobody is answerable.

eSanjeevani · 43 cr+ consults

No screening structure, no feedback loop to the referring worker, consultations "end as isolated single-step events" (PMC11422547). The referral seam below it is unowned.

U-WIN · 11.87 cr children

Tracks whether a dose was administered — self-logged by the vaccinator. Never asks whether the supply commitment behind the session was kept.

eVIN · 27,000+ cold-chain points

Depot-level stock visibility drove 80%+ fewer stock-outs — yet 26.3% of facilities still report one. The residual gap is at the point of use, not the depot.

ABDM · 96.85 cr ABHAs

National rails exist, but only 545 of 3,041 sandbox integrators completed certification. Integration must be an interface, not a dependency.

Kilkari · 21M+ mothers

One-way IVR education keyed to registry stage. Assumes a patient phone — the assumption this population breaks daily.

Khushi Baby CHIP · 85k CHWs

Nearest competitor: CHW data collection, self-reported by the worker. No cross-tier promise verified by a second, independent tier.

The Idea

One ledger. One shape. Every handoff.

The platform has exactly one first-class entity — Promise. A referral, a vaccine-supply commitment, a specialist consult, a follow-up visit are all rows of the same shape with a different evidence source plugged in.

PROMISE MADECommitted by one tier to another — referral sent, session supplied, consult requested, follow-up enrolled.
DEADLINE SETDual clocks: field creation time recorded, SLA starts on server receipt — offline work never insta-lapses.
EVIDENCE — OR ITS ABSENCECaptured from the receiving tier: registration match, point-of-use log, structured response, round attestation. Silence is a miss.
ESCALATION ON MISSA named person is paged and must acknowledge. Unacknowledged escalations render red on their own dashboard.

The principle that makes it a ledger, not another registry

Evidence always comes from the tier that received the promise — never the tier that made it. U-WIN tracks the vaccinator's own entry; eVIN tracks the depot's own count; Khushi Baby tracks the worker's own reports. This system catches exactly what those designs cannot see: whether the commitment survived the seam between two independently-operating tiers.

Promise Types

Four live types. One schema. Infinite adapters.

New promise types are new evidence adapters on the same state machine — additive, not architectural.

Referral

Committed: ASHA/ANM refers patient to CHC.
Evidence: passive arrival match via existing OPD registration — QR scan, manual code, batch entry, or attestation fallback with reconciliation.
Miss → ASHA → Block MO → District nodal.

Vaccine-session-supply

Committed: PHC/CHC commits vaccine stock for a scheduled RI session (seeded from the ANM's monthly plan, independence flagged).
Evidence: single-tap point-of-use log at session date. Silence = miss at T+1d.
Miss → cold-chain officer.

Consult

Committed: worker requests specialist review from triage routing.
Evidence: structured response + voice note within SLA (urgent 4h / routine 24h) — store-and-forward, eSanjeevani-compatible interface.
Miss → requesting facility.

Follow-up

Committed: protocol enrollment (ANC week / IMNCI band / NCD stage) plus auto-generation for due children absent from a supplied session — U-WIN tracks the dose; we track absence follow-through.
Evidence: round-visit attestation.
Miss → supervisor, repeats only.

Roadmap adapters (same schema): diagnostics · medicine fulfillment · appointment slots · data-capture quality digests. Named interfaces, never rebuilds: eSanjeevani · ABDM HIP · U-WIN · eVIN.

Build Pipeline

Seven gated phases. The engine ships first.

Every phase ends in a hard gate; no UI is written before the state machine's test matrix is green. Cut order protects six uncuttables: engine, capture ladder, escalation/ack surfaces, GSM bypass, household registry, independence flags.

Gate G-P0P0 · ContractsPrometheus-frozen OpenAPI, Promise model, transition tables, evidence-timeout table, rule-bundle format. API contract freeze.
Gate G-P1P1 · Promise EngineGeneric scheduler, ladders, reconciliation — full transition test matrix across all four types before any UI.
Gate G-P2P2 · Field App MVPAirplane-mode flow: triage → refer → session log → attest. GSM bypass proven with data off.
Gate G-P3P3 · Capture + Ack ViewsArrival ladder live; MO/cold-chain inboxes; deep-link acks recorded with latency.
Gate G-P4P4 · Consult + Follow-upDoctor-tab round trip; child-absent auto-generation from sessions.
Gate G-P5P5 · Messaging & ExportsNon-accusatory SMS templates, mock outbox, RCH CSV + NDJSON.
Gate G-P6P6 · Hardening & DemoKPI formulas live with baseline mode; 9-beat demo runs on clean compose-up.

USP

The only platform that verifies whether cross-tier public health promises were kept — using evidence from the tier that received the promise rather than the tier that made it — catching the documented failures that persist inside systems already working as designed, and escalating every miss to a named person who must acknowledge it.
